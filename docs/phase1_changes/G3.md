# Phase 1 change fragment: G3 (Pages A: I-V, Voltage dependence, Distribution summaries, Comparison figures)

Written by the Pages A group (design section 15). G6 merges this into `CHANGELOG.md`, the guide and
the inventory; nothing else edits those files for G3.

## CHANGELOG-ready text

- Voltage dependence, Distribution summaries and Comparison figures now sit in the Explorer's
  right-hand inspector, like I-V: the **Data & analysis** tab holds their groups (**Sources**,
  **Plot**, and on Voltage dependence **Fit**; **Recipes**, folded, holds the window templates),
  the Section drop-down and the page's own verb button are gone while the page is in the Explorer.
- **Update plot** is each page's verb. On Voltage dependence it draws the fit you chose when one is
  waiting (and then does not gather again), otherwise it re-gathers, as *Analyze / refresh* did. On
  Distribution summaries and Comparison figures it is *Generate*. The count in brackets is the
  number of draft controls that differ from the figure on screen, never fewer than 1 while the
  figure is marked out of date, and 1 before the first figure; hovering lists them.
- The strips that were too wide for a side column are forms: Voltage dependence's one-row
  Analysis strip (Metric, Fit, |V|, Log y), Distribution summaries' Data and Analysis grids and
  Comparison's three per-type boxes. The long "Overlay box summary (linear quartiles; 1.5 IQR)"
  check box wraps when the column is narrow. The page fits the Explorer's smallest size (840 x 560).
- Comparison figures: Undo and Redo (and their keys) work from either inspector tab, not only
  while the Appearance section was showing. Applying a look from Style ▾ to a figure that will not
  draw is reported on the Style result instead of opening a warning dialog.
- Export ▾ lists the page's own exports; on Distribution summaries and Comparison figures they are
  greyed until a figure has been generated (the same rule as the old button).
- Source names and colours (Distribution summaries, Comparison figures) is offered in the Format tab
  under Series, because the names are the legend entries.

## Labels added

Inspector groups: `Sources`, `Plot`, `Fit`, `Recipes` (Voltage dependence); `Sources`, `Plot`,
`Recipes` (Distribution summaries, Comparison figures). Form labels on Voltage dependence:
`Metric`, `Voltage` (the |V| check box), `Y axis` (the Log y check box), `Fit`; on Distribution
summaries: `Measurement`, `Summary`, `Violin grid points`; on Comparison figures: `Figure`, and per
type `X`, `Y`, `Columns`; `Diagonal histogram bins`; `Measurement`, `Points`. Update plot's
tooltip reasons: `fit model: Apply pending` (Voltage dependence); `not generated yet`, `the ticked
sources`, `accepted-only`, `the measurement`, `the summary type`, `the violin grid` (Distribution
summaries); the same plus `the figure type`, `the x measurement`, `the y measurement`, `the pair
features`, `the histogram bins`, `the facet columns`, `the point layout`, `the box overlay`,
`log x`, `log y` (Comparison figures); `an earlier change to the controls or sources` where the
figure is marked out of date but no control differs now.

## Labels removed (while the page is hosted in the Explorer)

The page's own toolbar row (Section drop-down, `Analyze / refresh`, `Apply fit`, `Generate`,
`Export ▾`, `Reset figure`: see F); Voltage dependence's `Apply fit` button and the inline words
`Metric` / `Fit` of the old strip (the objects stay, hidden; the button's text still reads
`Apply fit ●` while a fit waits); the Data / Analysis / Appearance / Export boxes of Distribution
summaries and Comparison figures (hidden husks); the group-box **titles** of Comparison's three
per-type boxes (`Facets · one panel per source`, `Pair matrix · select two to five features`,
`Individual observations · optional descriptive box overlay`) are now headings inside the box,
so they wrap. Comparison's page minimum size is 480 x 360 while hosted (700 x 500 alone) and
Distribution summaries' is 480 x 360 (650 x 480 alone). The sentence under the canvas buttons on
Comparison ("Canvas magnification · exports retain the full figure") wraps.
