Written by the shell group (design section 15). G6 merges this into `CHANGELOG.md`, the guide and

## CHANGELOG-ready text

- The Analysis Explorer's header is one 24-pixel line above the tool tabs: **Analysis home**, the
  context ("pore A · channel 1 · 3 recordings open", cut with an ellipsis when it does not fit,
  whole in its tooltip) and the status chip. The chip's tooltip adds "Out of date: <reasons>" while
  **Update plot (n)** has pending changes.
- The two button rows under the old header are gone. **Refresh current** is **Update plot ▾ ▸
  Refresh from recordings**; **Save to Figure Library…**, **Save figure bundle…** and **Figure
  Library** are items of **Export ▾** (the first two are off, as the buttons were, while a page has
  no result to save); **Refresh availability** is a button inside **Analysis home**.
- **Style ▾** applies a look, as one Undo step per page: **This page** or **Every open page**, each
  listing the six built-in looks (the four journal looks included) and the looks saved on this
  computer. "Every open page" reaches the figures open now; a figure opened later starts plain.
  After a batch the front page's status line says "<look> applied to N pages; Undo is per page." and
  names any page that refused, with its reason; no dialog opens. **Undo style on N pages** takes the
  batch back on every page it styled, and is on offer only while each of those pages is still where
  the batch left it (an edit, an Undo or a Redo on any of them ends it).
- A look keeps the text styles you set by hand (a bold 16 pt title stays) unless you untick **Keep
  text styles I set by hand**; the choice is remembered. **Save this page's look as…** stores the
  page's look (never its typed words) under a name; **Manage saved looks…** lists the saved looks
  and deletes one.
- The inspector's tab, width, visibility and each group's open or closed state are remembered per
  user; ⌘1 and ⌘2 switch the tabs, ⌘Return (and the keypad ⌘Enter) is Update plot on every page and
  commits a box you are still typing in first. ⌘3 and ⌘4 do nothing.

## For the integrator

- `HistoryState.mark` is the depth of the undo stack plus the open run, so Undo then a DIFFERENT edit
  lands on the same number. `StyleService` does not trust it alone: it keeps `(mark, undo text,
  can_redo)` per page right after the batch and drops the batch on the first history announcement from
  any of those pages that differs (the `history_changed` signal of the adapter). A page whose adapter
  has no `history_changed` signal (the fallback's Distributions until G5) is still checked by value when
  the menu opens or Undo is asked. No change to `plot_appearance.py` is needed.
- `PlotAppearanceWidget` saved looks live in `QSettings` under `plot_appearance/user_presets_v1`, which
  `tests/conftest.py` does not wipe per test: a test that saves a look removes the key before and after
  (`test_p1_style.py` has the fixture).
- `QAction.menu()` returns a Python wrapper that takes the C++ menu with it when it is dropped; keep the
  submenu from its owner (`StyleMenu.scope_menu`) in tests, not from `entry.menu()`.
- The Explorer's own status bar is created the first time a page with no status line (Subpopulations)
  needs to say a Style result, and from Home.
- Measured at 840 x 560: the toolbar row is 502 px wide (budget 650), nothing overflows; the header is
  460 px wide for the figure column with a 253 px context; a hosted page reports a minimum width of 438.
