# Phase 1 change fragment: G2 (the Format tab)

Written by the Format group (design section 15). G6 merges this into `CHANGELOG.md`, the guide and
the inventory; nothing else edits those files for G2.

## CHANGELOG-ready text

- The inspector's **Format** tab is organised by element. A list at the top (**Figure**, **Title**,
  **X axis** with **Label** and **Numbers**, **Y axis**, **Legend** with one row per legend name,
  **Series**, **Fit label**, **Caption**, **Colour bar label**, **Marginal label**, **Colour map**,
  whichever the page has) sits over one properties panel that follows the selection. The page's
  appearance controls moved into those panels with their labels; nothing was rewritten and every
  setting is the one it was.
- Click a text on the figure (title, axis label or numbers, a legend name, the fit label, a
  caption): it is outlined, the Format tab shows it, and a **mini toolbar** floats beside it with the
  font, size, **B**, **I**, colour, alignment (the title) and **Edit text**. Click empty plot to
  deselect; a pan keeps the selection; double-click and right-click do what they did. The outline
  and the toolbar are never in an export. A list pick selects the same element and never changes
  tab. A series is picked from the list, not by clicking its data.
- Every property of an element says where it comes from: **● set here** (click it to clear that one
  property), **from figure (Ticks 10 pt)** with a link back to Figure, or **default**.
- **Reset element** clears the styles an element set on its own and keeps its words; on an axis it
  also takes the range and major tick back to Auto, in one Undo step. **Reset look** (Figure) puts
  fonts, sizes, colours and every element's style back to the defaults and keeps the words, axis
  ranges, annotation places and legend names. **Copy format** and **Paste format** carry an
  element's look (never its words) to another element, an axis to an axis, a figure's look to a figure.
- The X axis / Y axis panel is "Axis properties…" held open: range with **Auto**, major tick spacing
  and the units; **Log** is shown, read-only, with a link to the page's own box (it changes what is
  binned and fitted).
- One gesture is one Undo step. A run of clicks on a size box is one step (the 700 ms rule of the
  appearance boxes), on every page. Leaving the size box ends that run before another control's edit.
- The font box can follow the figure ("Figure font", the first row of every text's font box in the
  Format tab and the mini toolbar) or name Arial, Helvetica, Times New Roman, Courier New or any
  installed font for that one text.

## Recovery integration, 2026-11-03

- Applied the complete recovered G2 changes, including uncommitted tests. Preserved Phase 0's
  private font row and picker tooltips while adding the inherited-font row and shared fields.
- Every existing row control, its label, a page extra and the fit-label group calls
  `prepare_widget_move` before changing layout, preserving the Foundation ownership fix.
- Empty clicks in another plot now clear the selection, while notifications from another
  controller for the same click cannot undo a selection. Annotation drag claims expire before
  the next click. Tick outlines exclude the label's boundary pixel.
- `FormatPane.retire()` disconnects controller and appearance signals before the retained pane's
  page can be hosted again. The host calls this before clearing the hub.
- `controller.finish_style_run()` delegates to `host.commit_text_run()` on focus leaving a size
  control. Distributions' `apply_format_styles` combines axis style/range reset into one Undo.
- Figure Copy/Paste leaves the destination fit label's visibility, number switches and style
  alone. Text-element Copy/Paste still supports a fit label's text style.
- Page extras can expose `_nanoscope_format_visible()` for a view-dependent Colour map element.
  Controls are constructed and moved once; changing view changes list eligibility only.
- Matplotlib pages retain their existing Title/X/Y wording controls in Format, with no claim
  of selectable matplotlib canvas elements or per-element styling before Phase 3.
- Added regressions for layout-item invalidation, old private-font inheritance, selection after
  annotation drag, retirement, colour-map visibility, retained matplotlib wording controls,
  fit-label-safe Figure Paste and external Distributions Undo/Redo panel refresh.

Recovery validation so far is static only. Runtime tests are coordinated by the integration lead.
