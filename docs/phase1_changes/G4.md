# Phase 1 change fragment: G4 (Pages B: Event waveforms, Noise spectrum, Subpopulations)

Written by group G4 (design section 15). G6 merges this into `CHANGELOG.md`, the guide and the
inventory; nothing else edits those files for G4.

## CHANGELOG-ready text

- Event waveforms, Noise spectrum and Subpopulations keep their controls in the Analysis
  Explorer's right-hand inspector (**Data & analysis** tab) instead of a row or column above and
  beside the plot. The page's own Section drop-down, **Analyze / refresh**, **Export ▾**,
  **Reset figure** and **Reset view** buttons are not shown any more; the toolbar's
  **Update plot**, **Export ▾** and **Reset figure** and the status line's **Reset view ▾** do
  their jobs.
- Event waveforms: the groups follow the tab you are on. **Plot · Event-count map** (X, Y,
  Log x, Log y, Bins) shows with the Event-count heatmap tab, **Plot · Ensemble** (Normalize
  time, Align, Points, Pad %, Band) and the **Events** subset with the Ensemble tab. The
  **Event-count heatmap colormap** moves to the Format tab with the rest of the look.
- Noise spectrum: **Sources** (Recording, Compare with, Segment), **View** (Show, the options
  of the view on screen, Log-log axes, Amplitude spectral density), **Estimator** (Welch
  estimate, RMS noise band) and **Recipes** (window templates). The controls column on the
  left of the plot is gone, so the plot gets the room. The **Spectrogram colormap**, **colour
  limits** and **Log frequency** move to the Format tab.
- Subpopulations: **Sources**, **View** (Embedding, Colour by) and **Report** (Event gallery…,
  Colour the trace) groups. The report text stays beside the figures and is now always shown
  (it used to be shown only with the Analysis section); its position and both splitters are
  saved with the project exactly as before. The in-tab **Close** button is hidden in the
  Explorer, the page's minimum width is 520 px instead of 900 px, and the pointer readout sits
  in a row of its own at the foot of the page.
- Subpopulations' **Update plot** shows (1) while the page says the accepted set moved under the
  report ("accepted now: … — re-run to update"); it opens the analysis settings first, as
  Analyze… did.

## Labels added

Inspector groups: Event waveforms `Sources`, `Plot · Event-count map`, `Plot · Ensemble`,
`Recipes`; Noise `Sources`, `View`, `Estimator`, `Recipes`; Subpopulations `Sources`, `View`,
`Report`. Form labels: `Events` (the ensemble subset), `X`, `Y`, `Bins`, `Align`, `Points`,
`Pad %`, `Band` (the same words the strips had), `Colormap` and `Colour limits` (Noise, in the
Format tab's Colour map panel), `Embedding`, `Colour by`. Export ▾ on Subpopulations:
`Export report and tables…` and `Copy report`.

## Labels removed (while the page is hosted in the Explorer)

The page's own toolbar row: `Section` and its drop-down, `Analyze / refresh` (Update plot),
`Reset figure`, `Export ▾`, the Reset view button (all objects stay, hidden). Event waveforms:
the per-view `Export current figure…` / `Export data (CSV)…` buttons and `Typography and lines`.
Noise: the left controls column, the `Style` group (a hidden husk of legacy rows), the
`Export current figure…` and `Export data (CSV)…` buttons, `Refresh`. Subpopulations: `Copy
report`, `Export…`, `Close`. Nothing is removed from a page opened on its own.
