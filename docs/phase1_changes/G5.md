# Phase 1 change fragment: G5 (Distributions)

Written by G5 (design section 15). G6 merges this into `CHANGELOG.md`, the guide and the
inventory; nothing else edits those files for G5.

## CHANGELOG-ready text

- Distributions is hosted in the Analysis Explorer's inspector with its own adapter. Its
  controls move, unchanged, into groups on the **Data & analysis** tab: **Sources**, **Plot**
  (plot type, columns, bins, normalization, log axes **and the fit rows**: Fit stays inside
  Plot), **Fit display** (Confidence band, Residual strip), **Groups** (Features, Clustering)
  and **Recipes** (the template rows, **Import JSON…** and the 200-step ceiling note). The
  Section drop-down, the page's own toolbar, **Plot / Apply**, both **Apply fit** buttons and
  the Axis range boxes are no longer shown (their objects stay, hidden, and keep working).
- **Update plot** (⌘Return, also the toolbar button) is the page's one verb: it commits the
  data selection, the plot type and columns, the KDE overlay and both proposed fits, and draws
  once. Its count is the number of independent pending changes: each reason the plot on screen
  is out of date (the plot type, an axis column, the data selection, the accepted-events
  filter, the KDE overlay) plus one for a proposed fit model, and **1 ("not plotted yet")**
  before the first plot. The amber banner now reads "Press Update plot (⌘Return) to redraw."
- **Undo** and **Redo** in the toolbar are this window's whole-configuration history (analysis
  and look), and they now refresh the toolbar and the Format tab after Undo and Redo too
  (they announced nothing before). They left the Export section; **Export configuration
  JSON…** is in **Export ▾** (and in the figure's right-click menu, which now lists the same
  three exports), **Import JSON…** is in Recipes.
- **Lasso select** and its **Mode: Pan/zoom** label are on the page's status line, with
  **Reset view**.
- Format: click a detection-limit label ("below detection limit") to select it. A run of
  size-spin clicks on a figure text is one Undo step on Distributions too; leaving the
  size control, changing elements, or making a discrete edit finishes that run. Reset
  element and Paste format write all of the affected styles as one step. Resetting an
  axis also clears that axis's pinned range in the same step, keeping its words and the
  other axis's range.
- Axis properties keeps offering Log on a plot while the Plot group is collapsed.

## For the integrator

- `tests/gui/test_p1_page_contract.py`: remove `"distributions"` from `FALLBACK`; the full
  contract then needs one change for this page: the look/Reset/Undo checks read
  `adapter.format.appearance.history_mark()`, which is always 0 on Distributions (its
  appearance widget has no history of its own: the page's `PlotConfig` stack is the history).
  They should read `adapter.history().mark` (the same number on the seven widget pages).
- `tests/gui/test_p1_explorer_hosting.py`: `test_all_eight_pages_are_adopted_...` hard-codes
  that only I-V has its own adapter (`adapter.fallback is (key != "iv")`), and
  `test_widget_counts_stay_inside_the_ceilings_...` has Distributions at 28 added widgets +
  10%; with the fifth group frame ("Fit display") the page adds 33 (frames only).
- `tests/gui/test_p1_fallback_hosting.py`: its Distributions rows describe the fallback
  (the Axis range group inside Plot) and are replaced by `test_p1_distributions_hosted.py`;
  the fallback's `_distributions_adapter` can go.
- The Format extras are individual population controls: `extras["figure"]` contains Body
  text size; `extras["legend"]` contains the position hint, Reset position, event-count
  switch and entry checklist; `["caption"]` contains Provenance caption, and
  `["colour_map"]` contains Heatmap colormap. A control carries `_nanoscope_row_label` where
  its row had a label. The shared appearance widget supplies all common rows. No extra is
  an ancestor of that widget, so Format uses the element inspector rather than its legacy
  fallback.
- `_PlotsTextHost.apply_format_styles(styles, auto_range_of="")` is G2's atomic write door;
  `auto_range_of` may be `bottom` or `left`. `commit_text_run()` ends a size spin's run at
  focus-out. Inspector Style and Reset figure finish any preceding text run first, and
  announce only the completed history state while composing their changes.
- `history_mark()` retains the shared depth-plus-pending convention. It is not a revision
  id: StyleService must invalidate its batch on `historyChanged` (including Undo, Redo and
  pending typing), rather than allow an Undo followed by a different edit to reuse a mark.
